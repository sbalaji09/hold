The security-print rosette behind Callback's decisions: woven bands of phase-shifted sine strands, drawn from code at any size.

**Provide** `size`, and optionally `lobes`, `strands` and `amp`. Colour comes from `currentColor`.

- Under 64px, keep `strands` at or below 6, or the band fills in solid.
- Use it only as a seal: inside `Endorsement` and `SignOff`, and on the cover. Never as decoration, a loading state or a background.
