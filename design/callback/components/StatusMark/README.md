A bill's state as a small capitalised mark with a glyph. There are exactly six states.

**Provide** `status`. Override the word only to add a count ("Held · 2").

| Status | Treatment | Meaning |
| --- | --- | --- |
| `paid` | `line` outline, tick, `paid` text | Done. Deliberately quiet. |
| `scheduled` | dashed `line` outline, clock | Pays on the run date. |
| `checking` | dotted `graphite` outline on `graphite-tint` | Callback is running checks. |
| `calling` | `brass` on `brass-tint`, pulsing indicator | A line is open now. |
| `held` | `hold` on `hold-tint`, double hairline frame | Money stopped. |
| `needs-you` | `signatory` on `signatory-tint`, person glyph | A person has to act. |

- Never add "Fraud" or "Risky". The bill is Held, and its page explains why.
